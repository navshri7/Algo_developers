COMPREHENSIVE ALGORITHM COMPARISON: FOUNDATIONAL vs FRONTIER RESEARCH
====================================================================================================

EXECUTIVE SUMMARY
----------------------------------------------------------------------------------------------------
This report compares four centrality algorithms across synthetic and real-world datasets:

FOUNDATIONAL ALGORITHMS (Classical Graph Theory):
  1. K-Core Decomposition - Identifies nested core-periphery structure
     - Time: O(V + E), Space: O(V + E)
     - Detects: Structural cohesion, network hierarchy

  2. Betweenness Centrality (Exact) - Measures node importance in shortest paths
     - Time: O(V·E), Space: O(V + E)
     - Detects: Bridge nodes, network bottlenecks

FRONTIER ALGORITHMS (Modern Network Science):
  3. Katz Centrality - Iterative measure with attenuation factor
     - Time: O(V·E·iterations), Space: O(V + E)
     - Detects: Influence propagation, weighted connections

  4. Eigenvector Centrality - Importance based on connections to important nodes
     - Time: O(V·E·iterations), Space: O(V + E)
     - Detects: Hub nodes, network prestige

2. WHAT EACH ALGORITHM DETECTS
----------------------------------------------------------------------------------------------------

K-CORE DECOMPOSITION:
  Detects:
    • Core-periphery structure
    • Network hierarchy and layers
    • Structural cohesion groups
    • Robustness and resilience
  Best for:
    • Social network analysis
    • Identifying influential communities
    • Network stability analysis
  Limitations:
    • Doesn't consider path importance
    • Treats all edges equally
    • Undirected perspective

BETWEENNESS CENTRALITY (EXACT):
  Detects:
    • Bridge nodes and bottlenecks
    • Information flow control points
    • Network vulnerability points
    • Shortest path dependencies
  Best for:
    • Communication networks
    • Transportation networks
    • Finding critical infrastructure
  Limitations:
    • Computationally expensive O(V·E)
    • Assumes shortest path routing
    • Sensitive to network structure

KATZ CENTRALITY:
  Detects:
    • Influence and reachability
    • Weighted path importance
    • Attenuation-based importance
    • Connection quality and distance
  Best for:
    • Citation networks
    • Recommendation systems
    • Influence propagation models
  Advantages over Betweenness:
    • Considers all paths, not just shortest
    • Faster convergence
    • More stable for sparse networks

EIGENVECTOR CENTRALITY:
  Detects:
    • Hub nodes and prestige
    • Recursive importance
    • Network influence propagation
    • Spectral properties
  Best for:
    • Web page ranking (PageRank basis)
    • Scientific collaboration networks
    • Identifying key opinion leaders
  Advantages over Katz:
    • No attenuation parameter needed
    • Theoretically grounded in spectral analysis
    • Better for recursive importance


3. COMPARATIVE ANALYSIS
----------------------------------------------------------------------------------------------------

FOUNDATIONAL vs FRONTIER:
  Foundational (K-Core, Betweenness):
    • Established mathematical foundations
    • Well-understood properties
    • Deterministic results
    • Limited parameters
    • Slower for large graphs

  Frontier (Katz, Eigenvector):
    • Modern network science approach
    • Parameter-dependent
    • Iterative computation
    • Better scalability
    • More flexible modeling


4. RECOMMENDATIONS BY USE CASE
----------------------------------------------------------------------------------------------------

Small Networks (< 1000 nodes):
  • Use: Betweenness Centrality (exact)
  • Reason: Accurate, deterministic, manageable computation
  • Also try: K-Core for structure, Eigenvector for hubs

Medium Networks (1000-100k nodes):
  • Use: Katz or Eigenvector Centrality
  • Reason: Good balance of accuracy and speed
  • Also try: K-Core for fast structural analysis

Large Networks (> 100k nodes):
  • Use: K-Core Decomposition
  • Reason: Linear time complexity
  • Alternative: Approximate Betweenness

Citation Networks:
  • Primary: Eigenvector or Katz Centrality
  • Secondary: Betweenness for bottlenecks
  • Tertiary: K-Core for community structure

Social Networks:
  • Primary: K-Core for communities
  • Secondary: Eigenvector for influencers
  • Tertiary: Betweenness for bridges

Infrastructure Networks:
  • Primary: Betweenness for critical nodes
  • Secondary: K-Core for robustness
  • Tertiary: Katz for redundancy
